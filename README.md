# XX × XY — Wedding Website

A deliberately simple HTML + CSS starter for the wedding website.

## Files

- `index.html` — the page content
- `style.css` — all visual styling

## How to view it

1. Keep `index.html` and `style.css` in the same folder.
2. Double-click `index.html`.
3. It should open in your browser.

You can also drag `index.html` into a browser window.

## Where to customize first

Open `style.css`.

At the top you'll see:

    :root {
      --paper: #f3f0e8;
      --ink: #111111;
      --flower: #b21f2d;
      --soft: #d8d1c3;
    }

These are the main colors.

Then open `index.html` and look for:

- `XX × XY`
- `APRIL 17, 2027`
- `DURHAM, NC`
- the placeholder ceremony/reception information

Replace those when you're ready.
